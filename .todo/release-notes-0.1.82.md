## Hermes Anywhere v0.1.82

### 聊天回合收尾修正（真机反馈两例）
- **旧用户气泡不再冒到回复末端**：回合跑完后，列表最末不会再凭空多出一条蓝色用户气泡（内容往往是会话第一句原文）。根因是发送时的本地乐观行带原文、服务端落库行带注入标记，两者恒不相等 ⇒ 收尾合并把它当新消息插回本轮末尾；现已改为归一化比对 + 新增「陈旧回声」判据。
- **工具卡计数不再虚高**：回合过程胶囊不再显示「终端×43 / 视觉×21」这类远大于实际的数字，末条正文之后也不会再冒出本回合根本没调用过的历史工具卡（如 read_file）。done 帧现在是全量转写坐标，客户端已按尾窗裁剪并 rebase。

### 内置服务页重排
- 启动按钮改为**固定贴页底**的操作区，设置项再多也不会把它挤出屏幕。
- 设置项常显，去掉「高级设置」折叠与箭头。
- 状态胶囊移到标题行尾右浮，正文只带端口，窄屏不再把端口截成「127.0.0.1:8…」。
- **缺 Hermes 引擎时改为整页空态**：警示图标 + 一句解释 + 两个出口（进入安装向导 / 我装好了，重新检测），不再渲染标题、胶囊、端口密码与启动按钮。

### 本机部署向导
- 删除「进度 x / 5」标签、百分比与进度横条，进度只由步骤轨圆点表达。
- 步骤轨改为「每步等宽一列」网格，圆点与标签严格同列居中，首末两步不再偏出去。
- 未达态圆点补不透明容器底色，连接线不再从圆圈里穿过去。
- 安装日志区吃满卡片整宽（原来只包住一行文字，成了「半个黑块」），外层裁圆角；标题行整行高度 60pt → 28pt。

### 设置
- **平滑输出默认关闭**；开启时默认档位改为「极快」。平滑输出是打字机演出的额外一层，不影响消息到达，默认开着会让每条回复先慢速逐字演一遍。

### 稳定性
- 重拍 install_guide 金照基线（向导改版后基线同步）。
