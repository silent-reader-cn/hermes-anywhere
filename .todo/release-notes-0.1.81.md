## Hermes Anywhere v0.1.81

### 模型列表统一（#205 前置）
- 模型列表统一显示**原模型名**，不再是自造别名。
- 三处模型展示入口（模型列表页 / 上下文弹层 / 输入栏元信息 chip）**共用同一数据源**，杜绝「同一模型三种名字」。

### 聊天图片预览改进（#205）
- 图片预览的下载按钮**去掉文字字样化**，只留图标。
- 图片预览新增**「引用」**按钮：直接把图片引用进输入框，可直接发出。

### 工作区交互（#206）
- 工作区页在安卓上的**返回键**改为回到上一级目录，不再退到主页。

### 浅色主题深浅适配补修（#204）
- **聊天附件全屏预览**：图片大图保持媒体查看器语义（恒黑底），文档类预览改为跟随主题（浅色下不再是「黑栏 + 白正文」的割裂感）。
- **窄屏筛选弹层**：分组卡片的描边改为由分组统一提供，卡片外框**处处完整连续**，不再出现「只有被选中行有描边」。
- **窄屏折叠菜单**：菜单动作色改为随「主题 × 高对比度开关」解析，普通档显示普通蓝，不再恒为高对比度配色。

### 会话列表交互修正
- 会话列表 FAB 长按工作区菜单：命中项**只做球高亮**，不再重复叠加按下态反馈。

### 稳定性
- 刷新金照基线（窄屏会话卡片描边补齐后基线陈旧）。
