## 本次更新

这一版的重心是**安装向导**——全新装机时最容易卡住的那几步，都被真实测试机的反馈逐条修掉了。

### 安装向导

- **全新装机不再报「解释器缺失」**。官方安装脚本 2026-10 重写后，依赖环境改由 `pm` 建在 `installs/<id>/environments/<id>/venv` 下，客户端却还在找老的 `venv` / `.venv`，于是第四步必然失败。现在按候选表依次解析，并以 `facts.json` 的记录为准（多条安装取最新）。
- **适配官方新的步骤名**。脚本把 stage 从 `prereqs/agent/deps` 改成了 `prerequisites/repository/venv/python-deps/config/products/complete`，客户端仍下发旧名时会被判 `unknown stage` 直接失败。现在以 `-Manifest` 实际名单为准，两代命名都兼容（`-Manifest` 的解析也一并修好了——之前它从未真正取到过名单）。
- **主按钮移到标题行**：窄窗口、手机远程桌面下不再需要滚到页面底部才能继续。
- 界面整理：凭据行不再说「配对码交接」、只指向密码；详情卡去掉与向导条重复的步骤名；服务状态并入「允许局域网设备访问」一行；去掉向导条下方的说明卡，进行中改用胶囊式 loading 表达；括号与重复滚动条一并清理。
- 修掉 Tailscale 进度卡里左侧图标偏上一点点的问题（视觉上「说不上哪不对」的那种 1.75px），并补了守卫用例，将来调字号不会又只剩图标没对齐。

### 其他

- 会话列表：新增真实会话尾窗回归用例，守住「提问气泡不会冒到回复末尾」。
- README 更新：首图改为双端并置，同一个会话在 Windows 与 Android 上的对照。
