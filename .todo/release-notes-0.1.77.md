# Hermes UI v0.1.77

> 上一版：v0.1.76。以下为 v0.1.76 → v0.1.77 的完整说明（含区间内全部提交）。

## 新功能

### 宽屏侧栏「槽」：左栏与右侧内容区拉开一个感知台阶

- **起因**：宽屏下侧栏与右侧顶栏原本**零色差**（实测两处同为 `#000000`／同一页底色），全窗只有一个平面，分区信息仅剩两条 10% 白发丝线 —— 大屏上「哪里是侧栏、哪里是内容」读不出来。
- **做法**：新增侧栏「槽」底色令牌，由**页底色自动派生**一个感知明度台阶（按 ΔL\* 定档，不是固定 RGB 差）：
  - 深色：抬升 ΔL\* 10（`#000000` → `#1B1B1B`）
  - 浅色：下沉 ΔL\* 4（`#F2F2F2` → `#E6E6E6`）
  - 色相跟随页底色、饱和度折半；两处夹紧守住不变量（槽不得撞侧栏内最亮填充 `#2C2C2E`；浅色槽不低于 `#E0E0E0`）
- **口径**：侧栏**整列**（品牌行 / 工具区 / 会话列表 / 状态条）同底取槽色；右侧（顶栏 + 正文）保持页底色。窄屏不渲染侧栏列，**逐像素不变**。
- **设置入口**：设置 → 外观 → 「页面底色」里新增一行「**侧栏槽**」：`跟随页底色（自动，推荐）` / `自定义`（复用 HEX 输入 + HSL 双滑杆）。切到「自定义」这一步本身不改变任何像素（预填当前派生值）。顶部预览卡升级为**三段真渲染**（槽竖条 + 分栏线 + 页底色与居中卡片）。
- **派生实测值**：浅色 `#F2F2F2→#E6E6E6`、`#F2F2F7→#E6E6EC`、`#EDEDED→#E1E1E1`、`#F8F8F8→#ECECEC`、`#F1EFEA→#E5E3DF`、`#F6F3EE→#EAE7E3`；深色 `#000000→#1B1B1B`（动态色，高对比度档 `#262626`）、`#141414→#1F1F1F`、抬不动的 `#1C1C1C→#131313`（反向下沉）。

## 修复

- **深色页底色设置此前对宽屏外壳不生效**：主题层把深色 `scaffoldBackgroundColor` / `barBackgroundColor` 硬编码成 `#000000`，导致「页面底色」只被部分页面（看板 / 设置 / 记忆 / 任务 / 技能 / 下载 / 诊断 / 洞察…）消费，而**宽屏外壳、聊天顶栏、聊天正文、空态详情页**拿不到 —— 深色下改页底色会出现「同一窗口两套底色」。现已统一走深色页底色令牌（未覆盖时解析原生 `systemGroupedBackground`，保留动态色语义 / 高对比度档）。
- **侧栏槽面上的文字可读性（AA）**：浅色槽比页底色更深，而次要文字色 `#6A6A6F` 的明度是按页底色 4.838:1 定的 —— 直接放在槽上只有 **4.31:1，低于正文 AA 4.5**（命中的是侧栏分组标题与行内相对时间，宽屏列表是朴素行、没有卡片兜着）。新增「槽面上的次要文字色」令牌：对生效槽色二分压暗（只动明度），逐档守 4.5。

## 内部质量

- 新增守卫测试：派生值表逐档硬钉、四个不变量（含槽面文字 AA）、自定义/复位、深色默认动态色语义、宽屏外壳契约（窄屏无侧栏容器 key）。
- 新增「主题 × 侧栏槽」真渲染目检工装（7 场景 × 1400×900，渲染层 + 文件像素双证，环境变量门控、不参与全量测试）。
- 端到端回归：切页底色档 ⇒ 侧栏槽跟着变（逐档钉 hex）；自动档忽略传入的自定义值（标志权威）。
- 全量测试 **5922 过 / 238 跳 / 0 红**；窄屏像素守门对着改动前基线**零变化**；金照 26 例零变化（金照不覆盖宽屏外壳，故本轮无金照 churn）。
- CI（push main）8/8 jobs 全绿。
