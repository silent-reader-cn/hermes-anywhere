# Hermes UI v0.1.75

本次版本的主线是**手机与电脑的一键配对**：手机首次打开不再要求你手填「服务器地址 + 24 位密码」，而是由电脑端出 6 位配对码，手机扫到就能连。跨网（不在同一 Wi-Fi）可选装 Tailscale，或继续手填地址。

> 说明：v0.1.74 之后到本版之间的改动全部包含在本说明里（中间没有单独的 Release）。

---

## 新增 · 手机 ⇄ 电脑配对

- **手机端首启改成决策树**：第一问「Hermes 跑在哪台电脑上？」——① 电脑就在同一个 Wi-Fi（自动发现 → 6 位配对码）② 电脑在别处（配对码）③ 我还没在电脑上装 Hermes（一键复制下载链接，可发到电脑上的微信/QQ 再打开）。
- **桌面端部署向导重做**：步骤区改成**横向步骤条**（环境检查 / 拉取 Agent / 安装依赖 / 启动服务 / 手机配对），只展开当前步；向导的整体成功判据从「安装完成」改为**「手机已连上」**。
- **6 位配对码**：10 分钟有效、一次成功即作废；密码由两端后台交接，不需要你抄。
- **局域网自动发现**：桌面端广播应答，手机端扫到即连；发现不了时给三条自检 + 手填入口。
- **Tailscale 一键安装（可选，默认勾选）**：勾选后这一步替你下载安装并打开登录页，装好手机在任何网络都能连；浏览器里那一次授权仍需你自己点（Tailscale 官方不支持邮箱注册）。**不勾选也能用**：同一 Wi-Fi 下手机可直接连。
- **网络受限地区提示**：检测到 GitHub 不可达时，向导会提示先开启网络加速（代理）再安装，避免「拉取 Agent / 安装依赖」超时。
- **Windows 防火墙首次放行引导**：手机端自检新增一条，桌面端向导也加了提示——首次运行 Windows 可能弹一次网络访问询问，请点「允许」，否则手机连不上。
- **同机多地址折叠**：同一台电脑的局域网与 Tailscale 两条地址在「设置 → 连接」里折叠成一条主行（另有 N 个地址），展开即可切换。

## 修复

- **图片偶发不加载、点一下窗口才出现**：图片淡入的首帧是完全透明且**占着位置**，一旦动画时钟没推进（桌面窗口失焦等）就会永远停在那——现在关闭动画时直接给终态，并加了看门狗兜底，图片不会再「隐形等待你点一下」。
- **配对地址可能选到手机连不上的网卡**：原先会取「第一个非回环地址」，在开了代理 TUN、虚拟网卡（Hyper-V/WSL/Docker/VMware）或无线网卡没拿到 DHCP 的机器上会选中**根本不可达**的地址（表现为「配对码输了连不上」）。现在改为：排除链路本地 / 代理伪栈（198.18/15）/ 虚拟网卡，优先与默认路由同网段的那块网卡，且**每个候选都要真连上健康检查**才采用；一个都不可用时不再静默回退到 127.0.0.1，而是在向导里明确告警。
- **手机可能存下「死地址」**：配对应答原先回的是调用方传入的地址（可能是 127.0.0.1 或虚拟网卡），现在统一下发**校验过能连上的**地址。
- **兜底「我有服务器地址」表单成了死胡同**：现在可返回（回到你来时的那一屏）。
- 会话列表、下载、看板、工作区若干修复：多选态底部栏不再压住列表末尾 / 行 key 改为身份型、不再整屏重建元素 / 新建工作区在聊天里立刻可选 / 深滚列表刷新不再塌陷 / 刷新不再「闪一下」。

## 平台

- Linux tar.gz、macOS zip 的构建与自足性口径已补齐（媒体库依赖闭包等）；本机发布为 Android（arm64）与 Windows x64 安装包。

---

**文件**
- Android：`HermesUI-0.1.75-arm64-app-release.apk`（arm64，适配小米 14 等现代机型）
- Windows：`HermesUI-0.1.75-x64-setup.exe`

**升级方式**：手机装新版 APK；Windows 直接跑安装包覆盖安装（数据不动）。
