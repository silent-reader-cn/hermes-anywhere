# Hermes Anywhere v0.1.80

> 上一版：v0.1.77。以下为 v0.1.77 → v0.1.80 的完整说明（含区间内全部提交；v0.1.78 / v0.1.79 为中间 bump，本次一并覆盖）。

## 品牌

- **Hermes UI → Hermes Anywhere**：显示层全量更名（应用标题、引导页、文案、渲染图、文档）。
- 仓库同步更名 `hermes-keep` → `hermes-anywhere`，Linux 金照基线同步刷新（6 张）。

## 新功能

### 聊天：附件「+」按钮支持多选上传

- 一次可勾选多个附件批量上传，不再只能逐个添加。

### 宽屏洞察页：柱状图两列等高 + 时间线改为从左往右

- 消除右列图表下方的大片空白，两列卡片高度对齐。
- 时间线阅读方向由右往左改为**从左往右**（符合中文阅读直觉）。
- 守卫测试改用**可鉴别判据**（`chart.height > chartCard.height - 90` + 末排轴标签贴卡片底），能真正拦住「容器被拉伸、里面还是空的」那一形态。

### 本机部署向导接回「内置服务」入口

- 缺 agent 时，缺失卡的按钮**真进 5 步部署向导**（此前被改成打开官网文档，2592 行向导实际无人可达）。
- 向导末步与内置服务 Tab「启动并连接」走**同一份链**（自动登录 + `builtinId` upsert/activate），消灭第二份实现 —— 原向导硬编码 `127.0.0.1:8787` 与空密码，和 sidecar 实配（可改端口 + 首次加载生成 24 位随机密码）错配，装完连不上。
- 设置页「前往安装向导」改为进真向导（原开官网文档）；指路文案改写为真实可点层级「设置 → 桌面 → 内置 WebUI 服务」；凭据行只指路不展示明文密码（密码属秘密，不写日志/不进 toString）。
- 向导收尾失败**不静默**：行内红字 + 可重试。

### 窄屏会话卡片补描边

- 窄屏会话卡片加描边提升可辨识度。

## 修复

### 聊天：治「同一句话重复 N 遍」

- **真因在客户端渲染层**（非生成/线程/网络）：服务端 `already_streamed` 靠 token 尾部匹配判定续流，弱网丢 token ⇒ 标记失效 ⇒ interim 整段重投。
- **修法**：客户端整段指纹闸门 + 诊断埋点。
- 已在低负载下做 R3–R6 四轮全量权威复现，结论稳定。

### 聊天：done 收尾帧裁窗

- done 收尾帧按 50 条窗口裁剪，避免 `state.messages` 膨胀到整表（长会话收尾时延显著下降）。
- 修掉裁窗把「可渲染行不足窗口」那一支**裁反**的 bug（提问气泡跑到了回复下方）。

### 聊天：steer 不可用时不再自动转队列

- 改为直接报失败并交还原文，不静默改投队列。

### 设置页：其余四个二级页改走 go_router 栈

- 修掉同源返回缺陷（此前自建返回逻辑，返回层级错乱）。

### 窄屏：修「新增服务器后返回退到主页」的双栈分裂

- 窄屏会话卡片补描边的同时修掉导航栈分裂。

### 批量栏：修 #184 加载竞态

- 本地 40 轮红 6 → 修后 40/40 全绿。

### 窄屏筛选弹层顺序

- 「工作区」段提到「项目」段之前（按主人 2026-10-15 要求）。

## 内部质量

- 全量测试多轮低负载权威复现（R3–R6）：失败均为负载抖动（用例身份漂移，非确定性失败），代码未改动。
- MCP 工具列表用例改用 fake 数据**真跑**，不再靠 skip。
- 新增 done 收尾帧体量/裁窗收益的取证探针（`tools/probe_done_*.dart`），便于真机核对行数与体积。
- CI（push main）多轮 dispatch 全 job success。
- **Linux 金照基线刷新 2 张**：窄屏会话卡片补描边（`session_list_dark`）、宽屏引导页文案与布局变更（`onboarding_wide_dark`）—— 本机只能重拍 `goldens/windows/` 那份，Linux 基线由 CI `update_goldens` 生成后回填；逐张比对确认其余 24 张逐字节未变。
