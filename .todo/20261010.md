# 2026-10-10

## [已收口] 全应用移除聊天消息行的蓝色焦点环（产品指令，提交 `4f965c8`）

- **产品原话**：「聊天框文本点击居然有 focused 的蓝色框 这个很出戏 不应该显示」→（追补）
  「把全应用的这种蓝环都去掉」。
- **现象（截图取证）**：点击聊天正文后整条消息行外套 **2px 蓝圆角框**。
  像素实测：蓝像素众数 **`(0,95,184)` = `statusBlueText` 浅色档**（8,340 px，环外无同色）；
  矩形范围 `x 63..1609 / y 54..770` = **恰好一条消息行**（顶边在「主人说得对…」正文上方、
  底边在正文末行下方，与列表滚动位置无关）。
- **位置**：`lib/features/chat/widgets/chat_message_list.dart` 的 `_MessageRowDesktopEntry`
  —— 原批次 5B §D4「鼠标端入口」的键盘入口视觉（§G3「键盘焦点环 2px 蓝 + 仅键盘触发」）。
- **根因（两层叠加，均为实测，非推断）**：
  1. 触发钩子 `FocusableActionDetector.onShowFocusHighlight` 只在 `FocusHighlightMode.traditional`
     回调 —— 原设计的假设是「鼠标点击不进该档」。但 `FocusManager.handlePointerEvent`
     （`focus_manager.dart:2191-2204`）**只对触摸 / 触控笔事件**把 highlightMode 切回 `touch`
     （鼠标 / 触控板 / unknown 是**空分支**），而任何键盘输入（`handleKeyMessage`）又把它置回
     `traditional` ⇒ **桌面端恒为 traditional**，鼠标点击 / 移动永远关不掉它。
  2. 驱环的 `Focus.onFocusChange`（`focus_scope.dart:689`）给的是 `FocusNode.hasFocus`
     （**含后代入焦**），而点击正文会让行内 `SelectableText` 的 `EditableText` 拿走焦点
     ⇒ 行节点「有后代入焦」即点亮整行蓝环。
- **复现 / 验证（同口径对照，探针用完即焚）**：固定 `TargetPlatform.windows` 起聊天页，
  键盘先打一次键（traditional）→ 鼠标点击助手正文：
  修复前 `ring=1`（行节点 `hasFocus=true / hasPrimaryFocus=false`）→ 修复后 `ring=0`。
- **修法（产品口径 = 全应用移除，不只修「点击」这条路径）**：
  - 删环本体：`_focusHighlighted` + `onShowFocusHighlight` + `Stack/Positioned.fill` 蓝环；
    `_MessageRowDesktopEntry` 由 `StatefulWidget` 收敛为 `StatelessWidget`（无状态可收敛）。
  - 删令牌 `kFocusRingWidth` / `kFocusRingOffset`（`layout_tokens.dart`）＋ `layout_tokens_test`
    对应断言（全仓已无消费者）。
  - **键盘入口功能逐字保留**（环是纯视觉）：`Shift+F10` / `Menu` 键、Tab 可达性、右键
    `Listener`（#134 结论）都未动。
  - 新增源码级守卫 `test/app/theme/focus_ring_removed_guard_test.dart`：扫 `lib/` 禁止
    `onShowFocusHighlight` / `kFocusRingWidth` / `kFocusRingOffset` 复活（注释行豁免，
    允许保留「被删事实」的说明性注释）。
  - 测试契约翻转 + 补复现用例：`message_menu_entry_test.dart`「键盘导航显示焦点环」→
    「**不得**显示」；Tab 可达性判据改用行级 `FocusNode.hasFocus`（环不能再当信号）；
    新增「点击助手正文 / 用户气泡都不得出环（**windows 档**）」两例。
    ⚠️ 旧用例跑在测试默认 `android` 档（初始即 touch）⇒ 该 bug 自落地起**一直假绿**。
- **验收（实测）**：`analyze` **零告警**；`message_menu_entry_test` 14 过 4 跳；
  `test/golden/` **26 条全绿**（证明移除 `Stack` 对宽屏布局**逐像素无影响**）；
  全量 `flutter test` **5648 过 / 230 跳全绿**。
- **备注**：会话列表「当前会话」的**蓝色左轨条 + 底色是持久选中态**（非焦点反馈，设计稿 #150），
  本次未动 —— 与「焦点环」是两回事；若主人也要去掉，另开条目。
- **待办（未做）**：主人当前跑的是**已编译的客户端**，本次改的是源码 ⇒ 需重新出包
  （Windows `flutter-windows-release` / Android `flutter-android-release`）才能看到效果。
